# Favourite Movie Intro

このプロジェクトは、学校の課題として作成した映画紹介サイトです。本来の課題内容では JavaScript を使う必要はありませんでしたが、より深く学ぶために自分で機能を追加してみました。

# 学んだこと

- 初めてJavaScript でスライドショーを作りました
- 初めてハンバーガーメニューを作りました
- 初めてフリップカード（カード反転アニメーション）を試してみました
- 初めてCSS Grid レイアウトを試してみました

課題に必要な範囲を超えて、自分で工夫しながら UI・JavaScript コンポーネントを実装しました。

# 使用技術

- HTML
- CSS
- Vanilla Javascript

# プロジェクトの目的

基本的なフロントエンドスキルの練習と、  
自分の成長を記録するための学習プロジェクトです。
